# DeathChestLite

A lightweight Minecraft plugin that turns a player’s death location into a protected, recoverable storage point.

## Overview

DeathChestLite helps players recover their items after death. When a player dies, the plugin places a protected chest at the death location and sends the location coordinates to chat.

The plugin is designed to stay lightweight while protecting the contents from other players and post-death explosions.

## Features

- **Smart chest sizing:** 27 items or fewer use a single chest; larger inventories scale to a double chest.
- **Inventory coverage:** Stores the player's inventory, armor, and offhand contents.
- **Ownership protection:** Only the chest owner or an administrator with the appropriate permission can open or break a protected chest.
- **Explosion protection:** Death chests are protected from explosions.
- **Configurable expiry:** Set how long a death chest remains before it drops any remaining items. The listed default is 600 seconds.
- **Location feedback:** Sends the coordinates and world name to the player after death.
- **Experience handling:** Configure whether experience is kept.

## Installation

1. Download a release compatible with your Minecraft and server version from [Modrinth](https://modrinth.com/plugin/deathchestlite).
2. Place the downloaded JAR in your server's \`plugins\` directory.
3. Restart the server.
4. Review the generated configuration and adjust it to your server.

Do not use a build intended for a different Minecraft or server version.

## Commands

| Command | Description | Permission |
| --- | --- | --- |
| \`/deathchest reload\` | Reloads the plugin configuration | \`deathchest.admin\` |

## Permissions

| Permission | Description | Default |
| --- | --- | --- |
| \`deathchest.use\` | Allows death chests to be created when the player dies | \`true\` |
| \`deathchest.admin\` | Allows access to any death chest and the reload command | \`op\` |

## Configuration

The published configuration options include:

| Key | Description | Listed default |
| --- | --- | --- |
| \`despawn-time\` | Time in seconds before a death chest expires | \`600\` |
| \`death-message\` | Message sent when a death chest is placed; supports the listed coordinate and world placeholders | Coordinate message |
| \`keep-experience\` | Whether to keep the player's experience | \`false\` |

Example values:

    despawn-time: 600
    death-message: "§aYour death chest has been placed at §e%x%§a, §e%y%§a, §e%z% §ain §e%world%§a."
    keep-experience: false

Use the configuration generated by the plugin as the source of truth for the complete set of options.
